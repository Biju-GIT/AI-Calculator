
# AI Calculator Using Java

## About the Project
AI Calculator is a desktop-based calculator application
developed using Java Swing.

It performs arithmetic calculations and supports
mathematical expressions and simple natural-language
inputs.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Square root
- Power calculations
- Trigonometric functions
- Logarithms
- Calculation history
- Graphical user interface
- Basic natural-language input

## Technologies Used
- Java
- Java Swing
- AWT
- Object-Oriented Programming

## Requirements
- JDK 8 or above
- Java-supported IDE or terminal

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Compile the Java file:

   javac -d out src/AICalculator.java

4. Run the application:

   java -cp out AICalculator

## Example Inputs

- 25+15
- 100/5
- sqrt(144)
- 2^5
- sin(30)
- what is 25 * 4
